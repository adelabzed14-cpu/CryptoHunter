# Crypto Hunter — نسخة Android أولية

- تطبيق Android أصلي باستخدام Kotlin وJetpack Compose.
- وضعان منفصلان: Spot وFutures.
- قراءة بيانات Binance العامة دون API Key.
- فحص أزواج USDT ذات حجم تداول مرتفع.
- تحليل إطار الساعة باستخدام RSI وEMA وMACD مبسط وATR.
- ترتيب أفضل 10 نتائج مع سعر مرجعي ووقف خسارة وثلاثة أهداف تقديرية.
- لا توجد أوامر تداول أو مفاتيح API أو صلاحيات سحب.

## بناء APK
يتطلب JDK 17 وAndroid SDK 35. يمكن بناء التطبيق من Android Studio أو عبر GitHub Actions. بعد نجاح Workflow، نزّل ملف Crypto-Hunter-debug-apk من Artifacts.

## حدود النسخة
هذه نسخة MVP أولية وليست نظام تداول احترافياً. Futures هنا تحليل بيانات العقود الدائمة فقط، ولا يوجد تنفيذ صفقات. لا تتضمن النسخة الحالية تنبيهات خلفية دائمة أو سجل صفقات أو اختباراً تاريخياً. MACD مبسط، ومستويات الدخول والخروج تقديرية ولا تضمن الربح. اختبر النتائج على حساب تجريبي قبل اتخاذ أي قرار مالي.
